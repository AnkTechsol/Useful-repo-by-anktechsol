# Instagram DM setup

One link for every keyword. It opens a file with the name and link of every repo, nothing else:

https://github.com/AnkTechsol/Useful-repo-by-anktechsol/blob/main/LINKS.md

`LINKS.md` is rebuilt automatically every day, so the link never changes.

## Comment keywords (all send the same link)
JUGAAD, MEHNAT, AKELA, BHEJO, FREE, TECH

In your comment-to-DM tool, add these trigger words (case does not matter in most tools):
JUGAAD, JUGAD, MEHNAT, MEHANT, AKELA, BHEJO, FREE, TECH

## DM text (use for every keyword)
```
Ye lo 👇 saare free GitHub repos ki list (naam + link):
https://github.com/AnkTechsol/Useful-repo-by-anktechsol/blob/main/LINKS.md
Roz update hoti hai. Kuch samajh na aaye to reply karo.
```

### Short version
```
Bheja 👇
https://github.com/AnkTechsol/Useful-repo-by-anktechsol/blob/main/LINKS.md
```

## Public comment reply (rotate these)
- "Bhej diya DM me 📩"
- "Check your DMs 👀"
- "Link inbox me hai, dekho!"

## Notes
- Instagram tools send the DM only after the comment. If someone has DMs closed, the tool cannot send.
- Meta private replies expire 7 days after the comment.
