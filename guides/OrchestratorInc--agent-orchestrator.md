# OrchestratorInc/agent-orchestrator

[Open the repo](https://github.com/OrchestratorInc/agent-orchestrator) · Setup level: **Easy** · Cost: **free (Apache-2.0)** plus the coding agents' own accounts · Works with: **Claude Code, Codex and 30+ coding agents** · Written from its README on 2026-10-22

## What it is
A desktop workspace (Orchestrator.inc) for running many coding agents on one project. Every task gets its own worker, isolated workspace and feedback loop, and you follow workers, pull requests, CI runs and reviews on a live Kanban board.

## Who it's for
Founders, freelancers and team leads who want to manage AI agents like a small team instead of babysitting terminal tabs.

## Use cases
- Split a feature into tasks and hand each to a different agent.
- Track every agent's PR, CI result and review in one board.
- Send CI or review feedback back to the worker that wrote the code.
- Use the phone app to check progress away from the laptop.

## How to set up
1. Download the desktop app for your platform from the repo's Releases (macOS, Windows, Linux builds are listed in the README).
2. Open it and point it at the repository you want it to manage; the app runs its daemon for you, no CLI needed.
3. Create a "New task", describe the outcome and pick the coding agent and model.

## Watch out
- On macOS, if the app says the developer cannot be verified, the README says to right-click and choose Open.
- The agents it runs still need their own accounts and cost money to use.
