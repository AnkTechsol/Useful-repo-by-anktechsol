# debpalash/VoiceStudio

[Open the repo](https://github.com/debpalash/VoiceStudio) · Setup level: **Easy to Medium** · Cost: **free (AGPL-3.0)**, runs on your own computer · Works with: **desktop app, plus a local API and MCP for agents** · Written from its README on 2026-10-21

## What it is
A desktop app for voice cloning, voice design, video dubbing, dictation, transcription and audiobook creation in 646 languages. Local workflows run on your own hardware.

## Who it's for
Creators and small businesses who need voiceovers, dubbed videos, transcripts or audiobooks, including in Indian and other languages, without paying per minute.

## Use cases
- Voiceovers for reels in several languages.
- Dub a video into another language with timed speech.
- Transcribe calls, interviews and voice notes.
- Turn long text into an audiobook.
- Dictate with a floating widget.

## How to set up
1. **Easiest:** download the app from the Releases page (macOS .dmg, Windows .exe, Linux AppImage or .deb).
2. **One command (macOS/Linux):** `curl -fsSL https://voicestudio.sh/install | sh`. On Windows use the PowerShell command in the README. Read the script first if you prefer.
3. Open **Voice cloning**, pick a voice or add a clean reference recording, type your text, and generate. Install the model it asks for.
4. Hardware: Apple Silicon and NVIDIA GPUs are fastest; a CPU-only PC works but is slower (about 5 GB free disk for the CPU setup).
5. Let your AI do the install: paste the "Install with prompt" text from the README into Claude Code or Codex.

## Watch out
- **Clone only voices you have permission to use.** The README has a responsible-use section; model weights and generated output have their own terms.
- Large downloads for models.
- AGPL licence: fine for your own use; check the terms before building a product on it.
