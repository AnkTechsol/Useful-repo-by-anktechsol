# Tracker

- `content-tracker.csv`: one row per video. When `scripts/update.py` finds a new repo (see `NEW.md`), add a row with its `added_date`. Fill the metrics columns after posting.
- `../DM-LINKS.md`: DM text and keywords for the comment-to-DM tool.

`video_status` flow: idea, script, motion-graphics, edited, posted.
Rows marked `seed` come from the first import; they are a ready backlog of video ideas.
